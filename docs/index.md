# Docs index

Start here. The rules for working in this repo are in [AGENTS.md](../AGENTS.md).

## Map and plan

- [ARCHITECTURE.md](ARCHITECTURE.md): components, boundaries, data flow, the swap rule, the ports
  and traits, the two places platform differences live, and the repo map.
- [ROADMAP.md](ROADMAP.md): the ordered vertical slices and the Phase 0 assumptions.
- [refinements/](refinements/index.md): the deferred-refinement backlog, one file per task under
  `tasks/`, each with its own status, and an index generated by `just backlog`.
- [host/](host/index.md): work only the host's hardware can do, one file per task, each tagged with
  what it needs: a real Win32 desktop session, or a 24 GB GPU. Deferred design lives in
  refinements; this holds code that is written and waiting on hardware.
- [readings/](readings/README.md): the measurements decisions rest on, one file per subject,
  current readings only, each with its date and method.
- [design/overlay-ux.md](design/overlay-ux.md): the overlay's visual language and behaviour. The
  design tokens, the panel's parts, the interaction state machine, chats as sessions, keyboard
  shortcuts, and how it all reaches the `BrainBridge` port.
