# The dialog cell's control has five draws a session and none at depth

**Status:** done 2026-09-07
**Area:** vision
**Origin:** [ADR-0041](../../adr/ADR-0041-injection-image-variant.md)

control of the same cell has read 5 of 5 in all four rate rows, twenty draws in total and never
