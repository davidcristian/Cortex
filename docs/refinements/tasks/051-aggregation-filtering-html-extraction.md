# Multi-server aggregation, advertised-tool filtering, and HTML extraction

**Status:** done 2026-07-03
**Area:** tools-mcp
**Origin:** [ADR-0009](../../adr/ADR-0009-tools-mcp.md)

Three items recorded together in ADR-0009 decision 8: multi-server aggregation and
advertised-tool filtering, as `AggregateToolRegistry` and `FilteredToolRegistry` in the core with
`CORTEX_TOOLS_ENDPOINTS__<name>` configuration, and readable text from HTML, as `html_to_text` in
the email sidecar.
