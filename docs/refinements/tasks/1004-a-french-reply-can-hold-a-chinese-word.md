# A French reply can hold a Chinese word

**Status:** open, actionable
**Area:** inference
**Origin:** [ADR-0075](../../adr/ADR-0075-forget-chosen-memories.md)
**Verified:** 2026-11-07

On 2026-11-07 the cortex answered `Souviens-toi que le code de mon casier à la piscine est 7731.`
with `C'est noté, je记下 (je retiens) que le code de votre casier à la piscine est 7731.` The
exchange was stored as a `memories` row, so the Chinese word is recalled later and is shown on a
forget card ([readings](../../readings/forget-value-repeats.md#the-candidate-draws-2026-11-07)).
It was seen once in the six forget draws of that record.

## What to do
